# 🌱 AgriMesh – Smart Village Resource Management System

AgriMesh is a web-based Smart Village Resource Management System designed to connect farmers and villagers. It helps manage agricultural resources, identify local requirements, and exchange goods through a simple barter system.

## 🎯 Objectives

- Connect farmers and villagers on a common platform.
- Manage available agricultural resources.
- Maintain village resource requirements.
- Enable resource exchange through a barter system.
- Encourage resource sharing and reduce wastage.

## 📌 Project Modules

### Module 1: User and Farmer Management
- User registration and login.
- Manage farmer and villager profiles.
- Store user and village details.
- Admin user management.

### Module 2: Agricultural Resource and Requirement Management
- Add available crops and resources.
- Manage resource quantities.
- Add village requirements.
- View available resources.

### Module 3: Barter and Exchange Management
- View available resources for exchange.
- Send exchange requests.
- Accept or reject requests.
- Track exchange status.
